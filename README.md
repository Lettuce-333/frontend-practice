# 🚀 Web 前端开发自主实践项目

## 📖 项目简介
本项目是《Web 前端开发》课程的自主实践作业。主要目的是通过实际动手编写代码，掌握 HTML5 基础标签、Git 版本控制以及 GitHub 仓库管理的基本流程。

## 📂 目录结构说明
本项目包含以下核心文件：

- `index.html` : 项目的主页面入口文件。
- `style.css` : 存放页面的样式代码。
- `images/` : 存放页面所需的图片资源（如 logo、背景图）。
- `docs/` : 存放相关的开发文档或笔记。
- `.gitignore` : Git 忽略规则配置文件。

## 🛠️ 如何运行
1. 克隆本仓库到本地：`git clone <仓库地址>`
2. 使用浏览器打开 `index.html` 即可预览效果。
